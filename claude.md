# Dual-Brand Design Rules

This document enforces the strict visual separation between our two core brands for all future code generation and UI design.

## 1. Brand: Bangkok Club Crawl (High-Energy Public Product)
**Vibe:** Electric, loud, high-energy, and action-oriented.

### UI Button Design
- **Primary Buttons:** Must be solid **Electric Pink (#FF2D95)** background with **Clean White (#FFFFFF)** text.
- **Usage:** Use these solid pink buttons generously across the `bkkclubcrawl.com` UI to drive instant booking conversions.

## 2. Brand: BEST Nightlife Thailand (Premium VIP Concierge App)
**Vibe:** Exclusive, premium, curated, and minimalist.

**Source of truth:** `PHASE4_STAGEB_PRODUCT_PAGE_CHECKPOINT.md` — the
approved BNT Product Page Template v1 visual system. The accent policy
below reflects that approved template.

### UI Accent & Button Design
- **Primary accent:** Fuchsia/magenta — not gold — is BNT's primary
  interactive and decorative accent. Current gradient family:
  **#EA003A → #820065**.
- **Usage:** Eyebrow labels, bullets, timeline markers, icons, links,
  editorial/serif gradient headings, and the mobile sticky booking bar.
- **Gold:** Reserved as a limited premium accent — currently primarily
  the CTA/button treatment where appropriate, not the primary decorative
  color.
- **Backgrounds & text:** Dark/near-black backgrounds and the approved
  neutral text hierarchy (bright headings, off-white body copy, muted
  secondary/tertiary text) remain unchanged.
- **Restraint still applies:** This is not permission to make every BNT
  surface fuchsia. Maintain the restrained, premium visual system
  established by Product Page Template v1 — fuchsia is a precise accent
  on a dark, minimal base, not a dominant fill.

## Core Color System (Shared & Specific)
- **BCC Electric Pink:** #FF2D95 (solid, high-energy — primary action
  buttons for Bangkok Club Crawl only)
- **BNT Fuchsia/Magenta Gradient:** #EA003A → #820065 (BNT's primary
  interactive/decorative accent — Product Page Template v1)
- **Champagne Gold:** #C9A84C (BNT's limited premium accent — CTA/button
  treatment)
- **Dark Base:** #111114, #1C1C1E
- **Clean White:** #FFFFFF
- **Charcoal Gray:** #2C2C2E

## Reasoning
Both brands use a pink/fuchsia accent, but at different intensities and
for different jobs. **Bangkok Club Crawl** uses solid, high-energy
Electric Pink buttons generously to drive instant booking conversions —
loud and action-oriented. **BEST Nightlife Thailand** uses a restrained
fuchsia/magenta gradient as a precise decorative and interactive accent —
eyebrows, links, icons, editorial headings, the booking bar — never as a
dominant solid fill, with gold kept as its limited premium accent. That
distinction in intensity and restraint, not the mere presence or absence
of pink, is what keeps BEST Nightlife Thailand feeling like an exclusive
concierge tool rather than a loud party flyer.
