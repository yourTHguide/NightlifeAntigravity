# Dual-Brand Design Rules

This document enforces the strict visual separation between our two core brands for all future code generation and UI design.

## 1. Brand: Bangkok Club Crawl (High-Energy Public Product)
**Vibe:** Electric, loud, high-energy, and action-oriented.

### UI Button Design
- **Primary Buttons:** Must be solid **Electric Pink (#FF2D95)** background with **Clean White (#FFFFFF)** text.
- **Usage:** Use these solid pink buttons generously across the `bkkclubcrawl.com` UI to drive instant booking conversions.

## 2. Brand: BEST Nightlife Thailand (Premium VIP Concierge App)
**Vibe:** Exclusive, premium, curated, and minimalist.

### UI Button Design
- **Primary Buttons:** DO NOT use solid pink. Use **Champagne Gold (#C9A84C)**, **Clean White**, or **Charcoal Gray** for primary action buttons.
- **Accent Rule:** Use **Electric Pink (#FF2D95)** strictly as a minimal secondary accent on `bestnightlifethailand.com`. It should only be used for:
  - Subtle hover glows
  - Thin borders
  - Active tab underlines
  - Small text links

## Core Color System (Shared & Specific)
- **Electric Pink:** #FF2D95 (Action for BCC, Accent for BNT)
- **Champagne Gold:** #C9A84C (Primary for BNT)
- **Dark Base:** #111114, #1C1C1E
- **Clean White:** #FFFFFF
- **Charcoal Gray:** #2C2C2E

## Reasoning
Too much solid pink breaks the premium luxury feel of **BEST Nightlife Thailand**. It must feel like an exclusive concierge tool, not a loud party flyer.

*Note: Always refer to these rules before generating any UI components for either brand.*
