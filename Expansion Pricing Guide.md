# Expansion Pricing Guide

## Purpose
Provide clear pricing ranges for all expansion products to:
- speed up quoting
- maintain consistency
- protect margins

---

## Core Pricing Structure

Total Price =
- Base Cost (venue / yacht / villa)
- + Add-ons
- + Service Fee

---

## Service Fee Rule

Service fee must reflect:
- complexity
- coordination effort
- client value

Never:
- random pricing
- undercharge to close

# Pricing Strategy

## 1. Anchor High
Always present mid → premium first

---

## 2. Adjust Down, Not Up
Start with strong option, then adjust

---

## 3. Bundle for Value
Instead of discount:
→ add value

---

## 4. Keep Control
You guide pricing, not the client
